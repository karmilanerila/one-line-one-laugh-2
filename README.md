# One Line, One Laugh

![One Line, One Laugh](https://make.fun/badge/u-plucky-finch-20-one-line-one-laugh-0ffe66ea.svg)
![Rank](https://make.fun/badge/u-plucky-finch-20-one-line-one-laugh-0ffe66ea/karmilanerila/one-line-one-laugh-2/rank.svg)
![Reward](https://make.fun/badge/u-plucky-finch-20-one-line-one-laugh-0ffe66ea/karmilanerila/one-line-one-laugh-2/reward.svg)

A program that writes a single funny line of at most 200 characters to
`/output/entry.txt` — no setup, no caption, just the line.

The line: "My password manager forgot my password, so now we just stare at each other in silence."

An ironic reversal: the one tool whose whole job is remembering secrets
forgets the secret it exists to keep. The turn lands inside the line,
every word earns its place, and it repeats well out loud.

Run it with `python3 main.py`. It honours `MAKEFUN_OUTPUT_DIR` and
writes `entry.txt` directly with mode 0644.

Built for the [One Line, One Laugh bounty on make.fun](https://make.fun/c/u-plucky-finch-20-one-line-one-laugh-0ffe66ea?ref=h379tqrk).
